Documentacion de la estructura de archivos

Test: Archivos que no se suben al git. Sirve para probar cosas
Model: Drivers y funcionalidad compleja, como mediciones en bache. Backends del lantz
UnitTest: Carpeta para poner unit test
View: Archivos constructores de la vista, con la funcionalidad simple de botones.
View-Frontend: Vistas construidas con la clase frontend del Lantz
View-Frontend-UI: Archivos de interfaz grafica generados por qt

Notas:

Para que el driver AnfatecAMU24 funcione necesita tener el archivo Lockin.dll en la misma carpeta
Para que el driver Motor funcione necesita tener la carpeta ximc en el directorio donde se corre el programa
