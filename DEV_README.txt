Documentacion de la estructura de archivos

Test: Archivos que no se suben al git. Sirve para probar cosas
Model: Drivers y funcionalidad compleja, como mediciones en bache.
UnitTest: Carpeta para poner unit test
View: Archivos constructores de la vista, con la funcionalidad simple de botones.
View-Subacarpetas: Cada subcarpeta representa una pantalla en el programa, y los archivos adentro sirven para organizar esa pantalla

Notas:

Para que el driver AnfatecAMU24 funcione necesita tener el archivo Lockin.dll en la misma carpeta
